# patch-ts

**Tree‑sitter‑aware patching CLI for AI agents and developers.**
Safely apply patches to **16+ languages** with knowledge graphs, SCITT provenance, MCP dashboards, parallel gates, and adversarial detection.

---

## What's New in v1.8.0

- **Project Knowledge Graph** — Semantic project index with call‑graph traversal & MCP resource.
- **SCITT‑Compliant Provenance** — Tamper‑evident, Ed25519‑signed audit trail.
- **MCP Apps Dashboard** — Interactive HTML patch review dashboard.
- **Parallel Multi‑Agent Gate** — Concurrent syntax, compile, cross‑file, & coverage stages.
- **Coverage Awareness** — Detects changed lines and reports test coverage gaps.
- **Adversarial Patch Detection** — Pattern‑based detection of injection, traversal, & exfiltration.

---

cargo install patch-ts
